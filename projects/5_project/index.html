Motor Memory Consolidation

A neuroimaging study investigating consolidation of motor memories using advanced analysis.

Overview

This project studies motor memory consolidation using neuroimaging data (fMRI/structural MRI) and advanced analysis tools. We combine preprocessing, region-of-interest analysis, and machine learning techniques to investigate how motor engrams stabilize after practice.

Methods

Data were processed with established neuroimaging pipelines; analyses include voxel-wise contrasts, ROI extraction, and temporal analyses of consolidation-related changes. Tools and techniques: AFNI-based processing, Python for data handling and ML, and statistical modelling to compare pre/post consolidation sessions.

Results & Notes

Representative results, figures, and ROI overlays (see thumbnail) illustrate consolidation-related activation patterns in motor networks. This page is a short project summary — detailed data and code are not linked here.

Technologies: fMRI, AFNI, Python, MATLAB, machine learning
